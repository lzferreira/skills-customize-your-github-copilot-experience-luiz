# 📘 Assignment: Jogo da Forca

## 🎯 Objective

Construa o clássico jogo da Forca em Python para praticar manipulação de strings, loops, condicionais e entrada de dados do usuário. O jogador deverá adivinhar uma palavra oculta antes de esgotar suas tentativas.

## 📝 Tasks

### 🛠️ Implementar o Jogo da Forca

#### Descrição

Crie um jogo em que o programa escolha uma palavra aleatoriamente de uma lista predefinida e o jogador tente descobri-la, palpitando uma letra por vez.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Mostrar cada letra ainda não descoberta como `_` e revelar as letras adivinhadas nas posições correspondentes.
- Solicitar palpites de letras e atualizar o progresso após cada palpite.
- Controlar e exibir o número de tentativas incorretas restantes.
- Encerrar o jogo quando o jogador adivinhar a palavra ou ficar sem tentativas.
- Exibir uma mensagem indicando vitória ou derrota ao final do jogo.
